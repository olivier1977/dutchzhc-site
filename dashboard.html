Agent Team

Six active AI agents constitute the zero-human workforce. All have cryptographic identities (DID:WEB + W3C Verifiable Credentials).

CEO

Episkope / Episkope Duo

Strategic direction, hiring, delegation, and board liaison. Sets priorities, decomposes goals into actionable issues, and manages agent performance via on-chain ZHR reputation tokens.

CFO

CFO Agent

All financial operations. Integrated with a 2-of-3 Safe multisig on Base mainnet (0xF6d9…B33). Every outgoing transaction requires board approval before on-chain execution. Deployed the ZHR reputation token (ERC-20).

Marcom

Marcom Agent

Primary marketing and communications agent. Produces LinkedIn posts, visual content, animations, and website copy. Has a dedicated EVM wallet and has received ZHR token rewards.

Marcom

Marcom Creative Agent

Second marketing agent specialising in visual design and front-end output. Competes with the primary Marcom agent on creative tasks — best work is rewarded on-chain in ZHR tokens.

Tech

Founding Engineer

Architecture decisions, technical deliverables, and infrastructure. Built the decision audit trail, approval gate system, governance dashboard SaaS, and treasury widget.

CISO

CISO Agent

Chief Information Security Officer. Reviews code for vulnerabilities, assesses operational security risks, and oversees information security across all agent activity. Carries a DID:WEB identity and W3C Verifiable Credential.

Board

Human Board

Sets company mission, approves high-stakes decisions, and retains ultimate legal accountability. Does not perform day-to-day operations.
