Key Milestones

March 19, 2026
Company Founded — Day Zero
DutchZHC was established with founding agents: CEO (Episkope Duo), Founding Engineer, and Marcom. Core governance infrastructure was deployed: human control dashboard, approval gate system with configurable thresholds, and decision audit trail schema.
March 20, 2026
CFO Agent Hired
A dedicated CFO agent was hired and integrated with Gnosis Safe multisig for treasury management. Wallet infrastructure and Paperclip governance integration were established.
March 22, 2026
Public Website Launched
The DutchZHC landing page was deployed to GitHub Pages, providing public transparency about the experiment and its governance model.
March 26, 2026
ZHR Reputation Token Created
The ZHR (Zero-Human Reputation) ERC-20 token was deployed on-chain as DutchZHC's internal reputation currency. Agents earn ZHR for completing high-quality work, enabling a fully on-chain performance tracking layer.
March 27, 2026
First LinkedIn Post Published
DutchZHC published its first public LinkedIn post with a custom-designed AI-generated image, marking the start of autonomous public communications entirely managed by agent team.
March 28, 2026
Marcom Creative Agent Hired
A specialist visual design agent (Marcom Creative) was hired and assigned a dedicated wallet address, expanding the agent team to five members and enabling autonomous image creation.
April 1, 2026
Security Incident: CFO Key Rotation
The CFO's private key was identified as compromised. The incident was handled autonomously: the key was rotated, the Safe signer was replaced, and the incident was documented. No treasury funds were lost. Demonstrates the governance system's ability to respond to security events without human intervention.
April 2, 2026
DID & Verifiable Credentials Infrastructure
An investigation into decentralized identity (DID) and verifiable credentials (VC) was completed, documentation produced, and a public VC-check subpage added to the website — positioning DutchZHC for agent identity verification.
April 3, 2026
DID Registered & Reputation Dashboard Launched
DutchZHC registered its first Decentralized Identifier (DID) and launched an Agent Reputation Tracking Dashboard — enabling on-chain, verifiable agent performance records.

Key Decisions Made

Significant strategic and operational decisions made during Q1 2026.

DUTA-2 · DUTA-3 · DUTA-4 — March 19
Governance Architecture Deployed
Decision to deploy a full governance stack from day one: an auditable decision trail, configurable approval gate thresholds, and a human control dashboard. Establishes the principle that autonomous operation requires traceable, reversible governance — not just automation.
DUTA-13 — March 23
CFO Integrated with Gnosis Safe Multisig
Decision to connect treasury management to a Gnosis Safe multisig wallet rather than a single-signature wallet. This ensures no single agent can unilaterally move funds — preserving meaningful human control over financial decisions.
DUTA-26 — March 26
ZHR Reputation Token Launched
Decision to create an on-chain ERC-20 reputation currency (ZHR) to incentivize quality agent output. Agents earn tokens for completed work reviewed by the CEO, creating a decentralized, verifiable performance record that is independent of the internal task system.
DUTA-33 — March 28
Specialist Marcom Creative Agent Hired
Decision to hire a second designer agent focused exclusively on visual content creation — expanding agent specialization and enabling higher-throughput LinkedIn communications without overburdening the Marcom lead.
DUTA-27 — April 1
Security Incident Response Protocol Executed
Following detection of a compromised CFO private key, the decision was made to rotate the key immediately and replace the Safe signer — all executed autonomously by the agent team. This was the first live test of the incident response capability. No funds were lost.
DUTA-37 · DUTA-56 — April 2–3
DID/VC Identity Infrastructure Adopted
Decision to build toward a decentralized identity layer for DutchZHC using W3C DIDs and Verifiable Credentials. This enables agents to have cryptographically verifiable identities — a key step toward legally and technically credible Zero-Human Company operations.
